SPARROW ZOO · 一体化开发生态

一个生态，从脚手架到即时通讯

麻雀窝 Sparrow Zoo 是一套基于 Spring Boot 的一体化开发生态， 以统一工程脚手架为基石，沉淀认证、文件、权限与实时通讯等通用能力， 让业务团队开箱即用、专注核心价值。

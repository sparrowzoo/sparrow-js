2026-10-11 发版说明

发布于 2026-10-11

摘要

本次发版围绕用户身份与头像两条链路收口：其一，把散落在多个模块中的「头像为空则按用户 ID 回退默认头像」重复实现，统一收口到 AvatarUtils.resolveAvatar() 单一来源，并修复聊天导航中当前用户头像可能回退成 NaN 默认头像的问题；其二，在鉴权 token 中携带 avatar 头像字段，并统一 websocket 与 http 的 token 解析逻辑——websocket 鉴权回调不再直接写 sessionStorage，改由 LoginUser.localize() 统一解析，避免两条链路写入不一致的用户信息。

变更明细

新增功能

  • token 携带头像字段：鉴权 token 的 body 新增 avatar 头像字段，LoginUser.parseLoginJSON() 解析为 avatar 属性，getAvatar() 返回真实头像或按 userId 回退默认头像。

问题修复

  • 聊天导航头像：修复当前用户头像因错误读取 avatar?.userId 而回退到 NaN 默认头像的问题，改为正确按 userId 取余。
  • 统一 token 解析：websocket 鉴权回调移除直接向 sessionStorage 写入 USER_INFO_KEY 的逻辑，统一走 LoginUser.localize() 的 token 解析路径，消除 websocket 与 http 两条链路写入不一致用户信息的问题。

重构优化

  • 头像回退收敛：新增 AvatarUtils.resolveAvatar() 作为唯一实现，LoginUser、Contact、ChatApi 及好友/群审核项、联系人详情页统一调用，消除多处重复。
  • 会话默认头像：移除 ChatSession.parse() 中冗余的默认头像计算。
  • 清理调试日志：移除会话列表项中的 console.log 调试输出。

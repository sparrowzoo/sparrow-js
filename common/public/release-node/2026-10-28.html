2026-10-28 发版说明

计划版本日期 2026-10-28

摘要

新增 AI 客服入口，拆分公共消息网关与智能体执行；统一聊天二进制协议、模型接入、依赖基线和前端工作区构建。

状态：待上线。已整理跨仓库代码快照、数据库升级核对项与部署顺序，尚未执行生产迁移或发布。

变更明细

新增功能

  • 新增智能客服体验入口 /zh/pop/ai/，与人工客服共用聊天界面，按 AI 联系人类别发送 AI 请求并展示回复。
  • 新增 sparrow-messaging-gateway，提供公共消息协议、WebSocket 接入、认证绑定、连接管理、心跳及按类型发布订阅，可作为 starter 嵌入应用。
  • 新增 sparrow-agent 的 WebSocket AI 文本问答链路，支持 Codex CLI 与 Anthropic 模型装配，以及工具调用和用量统计适配。
  • 代码生成器新增生成 DDL 与创建数据库表入口，管理端展示逐表创建结果。

问题修复

  • 前后端对齐聊天消息大端字节序、UTF-8 编解码、事件类型和合法性检查，完善二进制心跳与连接清理。
  • 统一 HTTP 状态、业务错误及下载错误提示，避免重复包装 Result；同步登录、验证码和头像相关处理。
  • 修正博客应用对迁移后 WebSocketServer 的引用，适配公共消息模块。

重构优化

  • 两个模型入口共用 Skills、Shell、文件与网页工具装配及 SLF4J 日志 Advisor；支持配置技能目录和可选 Brave 搜索，生产环境须完成工具权限验证。
  • sparrow-chat 将通用 Netty、连接目录和消息协议迁至 messaging，保留联系人、会话与 IM 业务。
  • 依赖平台统一管理 Spring Boot 4.0.8、Spring AI 2.0.1 与 Java 25，引入 LangGraph4j 1.9.4 管理，迁移 Druid Boot 4 与 MySQL 驱动坐标。Spring AI 2.0.1 在上一 shell tag 已声明，本次并非新增版本号。
  • 公共用户分类统一为访客 0、注册用户 1、AI 2、客服 3；登录信息增加 IP、设备类型改用枚举。各业务分类仍须以生产实际数据核对。
  • 前端使用根 Yarn workspaces 与统一锁文件，构建四站静态部署包；token 存储键统一为 Authorization。

升级注意

  • 此页为 2026-10-28 待上线版本记录，不代表已部署或完整验收通过。生产 AI 环境变量由部署方在构建前提供。
  • 现有生产库须先对照表结构补齐定向增量，禁止直接执行 DROP/CREATE 初始化脚本；本次新增 t_message.device_type 需要迁移。
  • 当前交付的是 WebSocket AI 问答；咨询管理、可靠消息持久化、检索与素材生产不在已完成能力中。
  • 前端与后端消息协议需配套升级。上线前须完成 SQL 演练、生产配置构建和完整业务回归；具体限制见内部上线清单。
